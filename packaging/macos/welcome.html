Install MoteField

Rango Labs

Choose the plug-in formats you want: Audio Unit (AU) for Logic Pro and GarageBand, or VST3 for compatible DAWs.

Works on Apple Silicon and Intel Macs running macOS 11 or later. A compatible audio host is required.

Before continuing: save your DAW project and quit your DAW.

Click Continue, then check the formats you want on the Installation Type screen. Both are selected by default and install in the correct folders for all users of this Mac.

Unchecking a format skips installation; it does not remove an existing copy. Click Install when ready. macOS will ask you to authorize installation.

Previously installed a manual-copy beta? Move its MoteField bundles out of your home Library plug-in folders before reopening your DAW, so the older copies do not hide this installation.

Your saved projects, user presets and exported audio are preserved.
