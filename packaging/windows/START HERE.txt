MOTEFIELD FOR WINDOWS / RANGO LABS / FREE DOWNLOAD

For Windows 10/11, 64-bit Intel/AMD, in any VST3-compatible DAW
(Ableton Live, FL Studio, Reaper, Cubase, Studio One, Bitwig and others).

Windows includes VST3 only. Pro Tools on Windows (AAX) is not supported yet.
Pro Tools on Mac is supported by the Mac installer.

INSTALL
1. Save your session and close your DAW.
2. Run the MoteField ...-Windows-x64-UNSIGNED.exe installer.
3. If Windows shows "Windows protected your PC" (see below), click
   More info, then Run anyway.
4. Approve the administrator prompt and finish the installer.
5. Reopen your DAW and rescan VST3 plug-ins. Look for MoteField by Rango Labs.
6. Put it on an audio track, choose a preset such as First Light, and raise Mix.

The installer puts the plug-in here:
C:\Program Files\Common Files\VST3\MoteField.vst3

Use your DAW's standard VST3 scan. Do not open the .vst3 file as an app.

WHY WINDOWS WARNS YOU
MoteField is free, and the Windows installer is not yet code-signed.
Windows SmartScreen warns about any installer from a publisher it doesn't
recognise yet, so you may see "Windows protected your PC" or
"Unknown publisher". This is a reputation warning, not a virus detection.

- Only run the installer downloaded from Rango Labs' official page.
- More info > Run anyway applies only to this one installer.
- Do not turn off Defender or SmartScreen.
- If your organisation's device policy or Smart App Control blocks the
  installer, MoteField can't be installed on that computer.
  The installer doesn't bypass those controls.

UNINSTALL
Quit your DAW. Open Windows Settings > Apps > Installed apps
(Apps & features on Windows 10), find MoteField, and select Uninstall.
